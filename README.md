# WHY ANT CANT DRIVE — Connecticut Learner's Trainer

A single-file, offline-first study app for a Connecticut learner driver.

**Live site:** https://ZEETHO.github.io/driving-trainer/

## What's inside
Nine tabs, one self-contained `index.html` (no build step, no dependencies):

1. **CT rules** — the graduated-licensing path, permit/license restrictions by phase, CT road laws, and a quiz.
2. **FAQ** — searchable answers to the questions families actually ask the DMV, each paired with a fix.
3. **Cockpit** — tap-to-reveal diagram of the 14 controls a new driver must find without looking.
4. **Pre-drive** — the outside / in-seat / engine-on ritual checklists.
5. **Signs** — shape-and-color code plus a sign recognition quiz.
6. **Right of way** — 12 intersection scenarios with SVG diagrams.
7. **Maneuvers** — step-by-step for starts, turns, lane changes, parking, merging, night, rain.
8. **Hazards** — what to do when it goes wrong (skids, blowouts, hydroplaning, etc.).
9. **Practice log** — the 20-session difficulty ladder + a printable 40-hour log.

Progress (seen controls, checklist ticks, quiz best scores) is saved to `localStorage`.

## Running it
Just open `index.html` in any browser. Or use the GitHub Pages link above.

## Disclaimer
Built as a study aid for a Connecticut learner. It teaches judgment and vocabulary; it does
not replace the required 30 classroom hours, 40 behind-the-wheel hours, a DMV-licensed
instructor, or the official
[Connecticut Driver's Manual](https://portal.ct.gov/dmv/licenses-permits-ids/ct-drivers-manuals).
CT rules were checked against the
[CT DMV teen driving restrictions](https://portal.ct.gov/dmv/licenses-permits-ids/teen-drivers-license/driver-restrictions-teens)
and [CT DMV teen licensing](https://portal.ct.gov/dmv/licenses-permits-ids/teen-drivers-license)
pages in August 2026. Laws change — confirm anything consequential with the DMV.
